# Lịch sử cập nhật

## 1.3.0 (2026-10-05)

### ✨ Tính năng mới

- Thêm trang **Lịch sử cập nhật** với mục lục cuộn nhanh theo phiên bản.
- Cho phép render nội dung từ file markdown trực tiếp lên giao diện.
- Hỗ trợ tìm kiếm nhanh trong bảng dữ liệu.

### ♻️ Cải tiến

- Tối ưu thời gian tải trang đầu tiên giảm khoảng `30%`.
- Chuẩn hóa lại khoảng cách giữa các khối nội dung.

### 🐛 Sửa lỗi

- Sửa lỗi cuộn trang bị giật trên trình duyệt Safari.
